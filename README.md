# Diggers Demo

A playtest build for Windows 10 and 11 (64 bit).

## Download and play

1. Download **[DiggersDemo.zip](https://github.com/Adrian323/Diggers-Demo/releases/latest/download/DiggersDemo.zip)**.
2. Right click the zip, choose **Extract All**, and extract it anywhere.
3. Open the `DiggersDemo` folder and run `DiggersDemo.exe`.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The game is not signed yet.

Saves and the log live in `%USERPROFILE%\AppData\LocalLow\Upstairs Games\Diggers Demo\`. If something breaks, send `Player.log` from that folder.

All builds: https://github.com/Adrian323/Diggers-Demo/releases
